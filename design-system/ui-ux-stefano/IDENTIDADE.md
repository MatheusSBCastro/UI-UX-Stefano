# Identidade da demonstração Stefano

Direção editorial de um estúdio de interfaces: fundo carvão, destaque lima,
tipografia ampla, composição assimétrica e objetos gráficos feitos em CSS/SVG.
A skill auxilia decisões; o conceito desta demonstração é uma escolha de projeto.
O `MASTER.md` contém recomendações para a categoria Design System/Component
Library. A identidade deste arquivo prevalece nos tokens visuais da demonstração.

| Token | Valor | Uso |
| --- | --- | --- |
| Fundo | #121413 | Corpo |
| Superfície | #191c19 | Painéis |
| Texto | #f2f3ed | Conteúdo principal |
| Texto secundário | #a3aaa0 | Apoio |
| Destaque | #d0f87b | Ações e desenhos |
| Alternativas | #c9b5ff / #ffb09c | Personalização interativa |
| Título | Manrope Variable | Cabeçalhos |
| Corpo | DM Sans Variable | Leitura e controles |

Fontes servidas localmente por pacotes Fontsource. Ritmo de entrada de 600ms;
hover curto; curvas contínuas suaves e pausáveis. No modo reduzido, fundos,
órbitas e partículas ficam estáticos e entradas não deslocam conteúdo.

Fluxo: introdução → laboratório interativo → peças disponíveis → prompt inicial.
Sem depoimentos ou métricas fictícias. Componentes externos ficam creditados.
